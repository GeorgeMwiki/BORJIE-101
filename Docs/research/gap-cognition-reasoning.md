## Score: 2.5 / 5 vs the domain-AGI target

**Why 2.5, not higher.** The *unit-level* cognition substrate is one of the richest in any
codebase: a disciplined 14-step kernel pipeline (`kernel.ts`), LATS MCTS
(`lats-search.ts`), beam ToT (`search-planner.ts`), 3-agent debate, Self-RAG, abductive
inference, world-model trajectory forecasting, recursive-HOT meta-thought, defection probe,
constitutional critic, reflexion + 4-pass nightly sleep, online conformal calibration. The
breadth equals or beats the SOTA paper menu.

**Why 2.5, not lower.** The load-bearing problem is **selection-thinness + wiring-unevenness
at the level of an actual production turn**, plus a **heuristic core where the SOTA target is
model-backed/learned**:

1. The **default live chat path does not run the disciplined kernel at all.** The mining
   chat orchestrator's default mode is a single Master-Brain LLM call with junior fan-out
   (`chat-orchestrator.ts:207-230`); `sov.kernel.think()` is behind a feature flag
   (`chat-orchestrator.ts:193-412`). On the main `/brain/turn` surface the kernel runs only
   as a **pre-flight safety gate** — the answer is generated by the persona path, NOT inside
   the 14-step pipeline (`brain.hono.ts:776-802`).
2. **No deliberate search runs on a turn.** LATS / ToT are exported and unit-tested but the
   orchestrator main-loop is a plain ReAct loop with **zero** plan/search/LATS references
   (`main-loop.ts` grep). LATS is reachable only via the flag-gated cognitive composer
   (`cognitive-composer-wiring.ts`), whose own history note says it "NEVER ran in production"
   before LP-01 and is still env-flag-gated + fail-safe-to-fast.
3. **Confidence is a heuristic `min()` of four regex scores** (`confidence.ts:35`), not a
   calibrated/learned probability. The real conformal calibrator exists
   (`conformal-calibration-online`, `conformal-confidence-gate.ts`) but its own docstring
   admits kernel `scoreConfidence` / `uncertainty-policy` "have ZERO live consumers"
   (`conformal-confidence-gate.ts:10-14`) — calibration is bolted onto the LLM-emitted float
   downstream, never feeding the kernel's groundedness/numeric checks.
4. **Metacognition / self-monitoring modules are ORPHANs.** recursive-HOT, per-thought
   self-model, autobiography, activation-probe, defection-probe, abductive best-explanation,
   world-model-tool: real, tested, but **no consumer in `kernel.ts`, `main-loop.ts`, or the
   production composition** (grep returned only the counter-model wired).
5. **Debate is not wired into the production sovereign kernel** (only into the
   `executive-brief.composition.ts` one-shot). The kernel `deps.debate` hook is dark on the
   live brain.

AGI target for this dimension = **4.5** (a reliable deliberate reasoner: shape-classified
planning, search on hard turns, learned calibration that gates action, self-monitoring that
catches its own errors before the user does). Current = **2.5** (rich parts, mostly
heuristic, default path bypasses the discipline).

## GAPS (every one with a buildable closure lane)

### G1 — Default live turn bypasses the disciplined cognition pipeline (BLOCKER)
**Current:** The mining chat orchestrator default path is a single Master-Brain LLM call +
junior fan-out (`chat-orchestrator.ts:207-230`); the disciplined `sov.kernel.think()` is
behind a flag (`:193-412`). The main `/brain/turn` surface runs the kernel as a **pre-flight
safety gate only** — the persona path generates the answer, explicitly *outside* the 14-step
pipeline (`brain.hono.ts:776-802`, "answer-generation stays on the persona path").
**AGI target:** Every consequential turn's *answer* is produced inside the disciplined,
self-monitored pipeline (judge, self-rag, drift, confidence, uncertainty), not just gated by
it. The pipeline is the reasoner, not a doorman.
**Closure lane:** Promote `sov.kernel.think()` (orchestrator main-loop) to the default answer
generator for consequential surfaces; demote the Master-Brain single-shot to fast-path/low-
stakes only. Thread the persona prompt + junior dispatch *inside* the kernel as tools (the
`orchestratorBindings` seam already exists, `compose.ts` Phase E.5.1). Area: brain-runtime.
**Effort:** XL

### G2 — No deliberate search (LATS/ToT) runs on a real turn (BLOCKER)
**Current:** `latsSearch` (full MCTS+UCB1+γ-backprop+reflection, `lats-search.ts`) and beam
ToT (`search-planner.ts`) are exported, unit-tested, and dispatched by stakes in
`planner-dispatcher.ts:107-132`. But the orchestrator main-loop has **zero** plan/search/lats
references (`main-loop.ts` grep). The only path to LATS is the env-flag-gated, fail-safe-to-
fast cognitive composer (`cognitive-composer-wiring.ts:18-34`, history: "NEVER ran in
production").
**AGI target (S5/S10):** hard, multi-step, verifiable-state decisions (licence renewal,
offtake structuring, capex) run a real lookahead/backtracking search with an LM value
function + self-reflection on failed sub-trees, anchored in environment ground truth.
**Closure lane:** Wire `dispatchPlanner` into the main-loop's deliberate branch so
critical-stakes / high-ambiguity turns expand-evaluate-backprop a real tree (the planner +
evaluator/expander oracles + `runLatsCot` already exist in
`cognitive-composition-deps-wiring.ts:163-360`); turn the composer flag ON by default for the
hard-edge band. Area: kernel-orchestrator.
**Effort:** L

### G3 — Confidence is heuristic `min()`, not calibrated; calibrator is not in the loop (HIGH)
**Current:** `scoreConfidence` = `min(groundedness, stability, review, numericalConsistency)`
where groundedness/numeric are regex sentence/number matches (`confidence.ts:29-93`). The
real online-conformal calibrator (`conformal-calibration-online`, `cognitive-engine`
`confidence-calibrator.ts`) is applied to the *LLM-emitted float* downstream
(`chat-orchestrator.ts:340-465`) and its own gate docstring states the kernel scorer +
uncertainty-policy "have ZERO live consumers" (`conformal-confidence-gate.ts:10-14`).
**AGI target:** a calibrated probability (conformal coverage / temperature-scaled) whose
miscoverage feeds back into a learned scorer, and that *gates whether the agent acts vs
asks* — not a regex min snapped to a tier after the fact.
**Closure lane:** Feed the kernel's structured `ConfidenceVector` (not the LLM float) into the
conformal ACI loop; consume the calibrated alpha *inside* `uncertainty-policy.ts` thresholds
so escalate/ask-back is calibration-driven. Replace regex groundedness with a claim-extractor
+ NLI support score (the `cognitive-engine` claim-extractor + groundedness-gate already
exist). Area: kernel-confidence + conformal.
**Effort:** L

### G4 — Metacognition / self-monitoring modules are ORPHANs (HIGH)
**Current:** recursive-HOT meta-thought (`metacognition/recursive-hot.ts`), per-thought
self-model (`introspection/per-thought-self-model.ts`, 512 lines), autobiography
(`metacognition/autobiography.ts`), activation-probe (`metacognition/activation-probe.ts`),

(`abductive/best-explanation.ts`), world-model-tool (`world-model/world-model-tool.ts`).

the counter-model is wired). The kernel's `self-awareness.ts` block injected at step 6 is a
*capability inventory + persona-drift gate*, not a live self-state monitor.
**AGI target (S11/S14):** the agent continuously models its own reasoning state ("am I
over-asserting without citations? am I in a failure loop? which hypothesis am I committing to
silently?") and acts on it (hedge, surface alternatives, request grounding) before the user
sees the answer.
**Closure lane:** Add a metacognition step to the kernel/main-loop that runs recursive-HOT +
defection-probe + abductive on the normalised draft and mixes the meta-thought / hedged
fragment back into a regen or the final text; persist per-thought self-model to the
reasoning-traces store. Area: kernel-metacognition.
**Effort:** L

### G5 — Recursive-HOT, defection, abductive are pure regex heuristics, not model-backed (MED)

**AGI target:** model-backed self-critique (LLM-as-judge meta-pass) that catches semantic,
not lexical, failure; abductive inference that weights priors by retrieved evidence strength.
**Closure lane:** Add an optional `judge`-port-backed deep mode to each module (the hook is
already foreshadowed in `recursive-hot.ts:14-16`); wire the existing Haiku judge as the
meta-critic. Area: kernel-metacognition.
**Effort:** M

## The three highest-leverage moves

1. **Make the kernel the reasoner, not the doorman (G1+G12).** Promote `kernel.think()` to
   the default answer generator on consequential surfaces so judge/self-rag/drift/confidence
   actually shape the answer, and add a ground-truth verifier on completion. This single move
   flips the whole dimension from "rich parts, bypassed" to "disciplined by default."

2. **Turn on deliberate search + calibrated gating for hard turns (G2+G3+G10).** Wire
   `dispatchPlanner` into the main-loop's hard-edge band, feed the kernel's structured
   confidence vector into the conformal loop, and actually compute self-consistency. This is
   the "knowing-when-it-is-wrong + thinking-harder-when-it-matters" core.

3. **Light up self-monitoring (G4+G6+G15).** Wire the orphaned metacognition modules +
   debate + a unified situational/blind-spots model into the pipeline so the brain catches its
   own over-assertion, runs multi-voice deliberation at stakes, and tracks its known-unknowns
   — the difference between an answer engine and a self-aware MD.

## Method note

Verdicts derived by reading source and tracing consumers (grep for import/call sites across
`services/`, `apps/`, `packages/`, excluding `dist/`, `node_modules/`, `__tests__/`).
"ORPHAN" = the only references found were the module's own code, its tests, its `dist/`, or a
DB-schema/comment registration — no live runtime path. Line numbers are from the working tree
on `integration/parity-final` as of 2026-06-08. The BN reference repo
(`Cursor Projects/BOSSNYUMBA101`) shares the same `central-intelligence/kernel` lineage
(same metacognition/conformal/reflexion module set), so these gaps are common to both.
