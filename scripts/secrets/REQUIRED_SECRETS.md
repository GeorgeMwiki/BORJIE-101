# Borjie — Required Secrets Manifest

**Canonical list of every secret/config value needed to deploy.** Generated for
the LITFIN port wave (branch `litfin-port-waves-2026-06-03`). Pair this with
[`.env.example`](../../.env.example) (full template, all vars) and
[`bootstrap-secrets.sh`](./bootstrap-secrets.sh) (generates the `[SELF-GEN]`
half).

## Status tags

| Tag | Meaning | Who provides it |
| --- | --- | --- |
| `[OPERATOR]` | Third-party key/endpoint a human pastes. Cannot be generated. | You (from the provider's dashboard) |
| `[SELF-GEN]` | Cryptographic secret minted locally. | `sh scripts/secrets/bootstrap-secrets.sh` (or `pnpm gen-secrets`) |
| `[FLAG default-off]` | LITFIN-wave feature gate. Ships OFF; opt-in after a staging canary. | Leave unset until canary |

> **Never commit a real value.** `[SELF-GEN]` secrets land only in
> `.env.local` (gitignored). `[OPERATOR]` keys go in `.env.local` or your
> platform secret store. `.env.example` carries placeholders only.

### Ledger role login setup (`migration 0275_ledger_roles.sql`)

The migration creates **NOLOGIN group roles** (`borjie_ledger_writer`,
`borjie_ledger_reader`). The operator creates the **LOGIN roles** and points
the two ledger DATABASE_URLs at them:

```sql
CREATE ROLE ledger_engine_app LOGIN PASSWORD '<LEDGER_ENGINE_APP_PASSWORD>';
GRANT borjie_ledger_writer TO ledger_engine_app;
CREATE ROLE ledger_read_app   LOGIN PASSWORD '<LEDGER_READ_APP_PASSWORD>';
GRANT borjie_ledger_reader   TO ledger_read_app;
```

Then set `LEDGER_DATABASE_URL` (engine) and `LEDGER_DATABASE_URL_READONLY`
(read) with the matching creds. The two passwords are minted into `.env.local`
by `bootstrap-secrets.sh` as `LEDGER_ENGINE_APP_PASSWORD` /
`LEDGER_READ_APP_PASSWORD`.

## `[FLAG default-off]` — LITFIN-wave cognitive gates

All ship OFF (fail-soft: a broken adapter degrades to prior behaviour). Truthy:
`1` / `true` / `on` (case-insensitive). Flip only after a staging canary.

| Var | Default | Where it's used |
| --- | --- | --- |
| `BORJIE_COGNITIVE_COMPOSER_ENABLED` | OFF | Deep composition pipeline (LATS / Self-Discover) — `cognitive-composer-wiring.ts`. |
| `BORJIE_SEMANTIC_CACHE_ENABLED` | OFF | Semantic cache on the LLM call path — `lp30-kernel-ports-wiring.ts`. |
| `BORJIE_INTENT_VERIFIER_ENABLED` | OFF | Intent-verifier in the think-pipeline — `lp30-kernel-ports-wiring.ts`. |
| `BORJIE_INTENT_VERIFY_STRICT` | OFF | Fail-closed verifier verdict (else shadow mode). Requires the verifier ON. |
| `BORJIE_LEARNING_LOOP_ENABLED` | **ON** | Learning-loop subscriber (reflexion + belief) — `learning-loop-port.ts`. Set `0`/`false`/`off` to disable. |

## Deploy checklist

1. `sh scripts/secrets/bootstrap-secrets.sh` → mints `[SELF-GEN]` into `.env.local`.
2. Paste every `[OPERATOR]` value (table above) into `.env.local` / secret store.
3. Apply migrations (incl. `0275_ledger_roles.sql`); create the two ledger LOGIN roles.
4. Leave `[FLAG default-off]` gates OFF; enable per-flag after a staging canary.
5. Confirm `git status` shows **no** `.env.local` / `.env` staged (both gitignored).
